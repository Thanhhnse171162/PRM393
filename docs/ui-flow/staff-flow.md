# Staff Flow

Bottom navigation: **Trang chủ · Lịch đặt · Quét QR · Quản lý sân · Tài khoản**

```
Login (staff account created by Admin) → /staff/home (assigned branch only)
Trang chủ: current operations dashboard, today's summary
Lịch đặt: today's bookings, search / filter by status, court, time
Quét QR: scan → booking detail → Check in
        → collect remaining payment (Cash / transfer) → mark InProgress / Completed
Quản lý sân: set court status (Active / TemporarilyBlocked / Maintenance)
Walk-in booking: choose court + consecutive slots → collect payment
Thông báo: operational notifications
```
