# Admin Flow

Bottom navigation: **Tổng quan · Quản lý · Lịch đặt · Báo cáo · Tài khoản**

```
Login → /admin/home
Tổng quan: key numbers (bookings, revenue, occupancy)
Quản lý:   branches · courts · sports · staff accounts & assignment · opening hours · prices · system settings
Lịch đặt:  all bookings across branches, cancellation / refund processing
Báo cáo:   simple reports (revenue, bookings per branch / sport)
Tài khoản: profile, logout
```
Admin does not use QR check-in as the main workflow.
