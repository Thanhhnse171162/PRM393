`stitch-courtgo.jpg` is the CourtGo Sports Complex artwork referenced by the
user-supplied Stitch login export at
`docs/design/stitch/courtgo_ng_nh_p_chu_n_h_a_tinh_g_n/code.html`.

It is bundled for the decorative brand headers so they work offline. It is not
used as a substitute for a branch/court photo from the API. The Flutter viewport
excludes the navigation painted into the top of the supplied artwork.
